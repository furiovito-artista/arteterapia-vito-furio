# Arteterapia di Vito Furio

Sito professionale statico modificabile tramite Pages CMS e pubblicabile come Cloudflare Worker.

- Configurazione CMS: `.pages.yml`
- Contenuti modificabili: `data/*.json`
- Fotografie: `images/`
- Configurazione Cloudflare: `wrangler.jsonc`

Sito pubblico: https://arteterapia-vito-furio.furiovito.workers.dev/
